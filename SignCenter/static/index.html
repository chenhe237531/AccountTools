使用教程

  • 添加账号：先在对应桌面应用里登录账号，然后点卡片里的 + 添加账号，把当前登录态保存为快照。
  • 切换账号：点击账号名 chip 即可切换。WorkBuddy 热加载秒切；Trae / Qoder 会先退出应用再重启（请保存好编辑器内容）。
  • 立即签到（卡片蓝色按钮）：只签到当前登录的那个账号——它已是当前账号，不会重启应用，秒级完成。
  • 全部签到（卡片灰色按钮）：依次切换该软件的所有账号各签到一次，完成后自动切回原账号。Trae/Qoder 每次切换都会退出并重启应用，账号多时耗时较长。
  • 全部平台签到（底部蓝色按钮）：对所有已启用平台执行「全部签到」。
  • 删除账号：点击账号 chip 上的 ×，仅删除本地快照，不影响应用内登录。
  • 自动签到：到底部设定时间后自动执行「全部签到」；需保持本服务运行。
  • 高级：在 data/config.json 里可为平台配置 checkin_command 钩子（签到时执行的 shell 命令，可用 $SIGN_PLATFORM / $SIGN_ACCOUNT 变量），接入真实签到 API。
