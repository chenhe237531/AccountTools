使用教程

  • 添加账号：先在对应桌面应用里登录账号，然后点卡片里的 + 添加账号，把当前登录态保存为快照。
  • 导入 JSON（支持的卡片会显示「⬆ 导入 JSON」）：选择外部导出的登录凭证 JSON（含 access/refresh token）。导入时自动验证有效性，账号以虚线紫色 chip 展示，签到时直接经官方 API 领取积分，不切换、不重启桌面应用；token 过期会自动用 refresh_token 续期。重复导入同一账号即更新凭证。
  • 切换账号：点击账号名 chip 即可切换。支持热加载的应用秒切；其他会先退出应用再重启（请保存好编辑器内容）。
  • 立即签到（卡片蓝色按钮）：只签到当前登录的那个账号——它已是当前账号，不会重启应用，秒级完成。
  • 全部签到（卡片灰色按钮）：依次切换该软件的所有账号各签到一次，完成后自动切回原账号。
  • 全部平台签到（底部蓝色按钮）：对所有已启用平台执行「全部签到」。
  • 删除账号：点击账号 chip 上的 ×，仅删除本地快照，不影响应用内登录。
  • 自动签到：到底部设定时间后自动执行「全部签到」；需保持本服务运行。
  • 设备重置（Trae 卡片）：切号过多提示「设备数量已达上限」时使用。需先完全退出 Trae；重置后账号掉线属正常，重新打开 Trae 直接点个人用户登录即可。
  • 高级：在数据目录的 config.json 里可为平台配置 checkin_command 钩子（签到时执行的 shell 命令，可用 $SIGN_PLATFORM / $SIGN_ACCOUNT 变量），接入真实签到 API。
  • 扩展：本控制台由插件化适配器驱动（app/agents/），新增软件 agent 只需按 _template.py 添加一个适配器文件。
